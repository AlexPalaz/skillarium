# Layout reference

PDF coordinates start at the **bottom-left** corner and are measured in points
(1 pt = 1/72 inch).

| Page size | Width | Height |
| --------- | ----- | ------ |
| A4        | 595   | 842    |
| Letter    | 612   | 792    |

To convert from a top-left origin: `y_pdf = page_height - y_top`.
