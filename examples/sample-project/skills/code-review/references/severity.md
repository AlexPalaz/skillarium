# Severity scale

| Level    | Meaning                                       | Merge?            |
| -------- | --------------------------------------------- | ----------------- |
| critical | Data loss, security hole, or outage           | Block             |
| high     | Wrong behaviour in a common case              | Block             |
| medium   | Wrong behaviour in an edge case               | Fix or follow up  |
| low      | Readability or minor robustness               | Author's choice   |
